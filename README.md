# TapFolio

> Um projeto estilo Linktree feito pra centralizar links de forma simples, bonita e profissional.

---

# Sobre o projeto

O TapFolio nasceu com uma ideia bem simples:

ter um lugar único pra compartilhar tudo.

Hoje em dia a gente acaba espalhando conteúdo em várias plataformas:
Instagram, GitHub, LinkedIn, portfólio, WhatsApp, loja, cursos, projetos e por aí vai.

O TapFolio resolve isso criando uma página única e personalizada com todos os seus links importantes.

A proposta do projeto é ser:

- simples de usar
- rápido
- responsivo
- bonito
- personalizável
- escalável

Tudo sem complicação.

---

# Objetivo

A ideia é permitir que qualquer pessoa consiga criar sua própria página de links em poucos minutos.

Mas além disso, o projeto também foi pensado como uma aplicação moderna e escalável, servindo tanto pra uso real quanto pra estudo de arquitetura fullstack.

 "Na verdade eu só queria um lugar pra por meus projetos KKKJ".

---

# Funcionalidades

- criação de perfil personalizado
- foto de perfil
- bio/descrição
- lista de links
- ordenação de links
- temas personalizados
- analytics de cliques
- responsividade mobile
- painel administrativo
- compartilhamento fácil
- suporte a redes sociais
